## Perfect-trader checklist VIGIL enforces (paper Demo)

1. Named setup + news catalyst (not rumor-only)
2. Observed move meaningful (~≥1% abs) OR refuse
3. Bull case **and** ≥2 bear points (anti confirmation-bias)
4. Invalidation pre-committed (exit rule before fill)
5. Session / liquidity risk labeled (after-hours)
6. Fixed paper size — never spray balance (FENN)
7. Bias circuit-breaker (FOMO / revenge / sunk cost)
8. Mark-to-market + mark-to-exit PnL for honest Demo scoreboard
